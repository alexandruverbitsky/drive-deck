# Using Drive Deck Lite

[Back to README](../README.md)

## Navigation

Use the left navigation rail—or the bottom rail on a narrow screen—to select All shortcuts, Favorites or Radio. Favorites contains the IDs listed in the published JSON configuration. Radio shows direct audio streams only.

Swipe the app area horizontally or choose a page dot. With the app area itself focused, Left/Right, Home and End navigate pages.

## Radio

Select a radio tile to start playback. The player provides Play/Pause, Mute and volume controls. The expand icon opens a larger player inside the dashboard; closing it restores the normal layout.

Interrupted playback uses bounded reconnection attempts. Use Retry if automatic recovery fails. Pausing cancels recovery. Reloading restores the last selected station paused, without autoplay.

Website tiles, including NTS, open separately. FIP plays directly in the radio player. Map shortcuts also open separately.

## Appearance and markets

Open the gear button to choose a theme or hide/show the market ticker. Pause unloads the external ticker; Resume loads it again. Market quotes may be delayed. Entries labeled CFD are CFD instruments, not cash index spot prices.

## Saved preferences

Theme, volume, last station and ticker visibility stay in this browser. They do not sync between the Tesla and phone. Clearing site data or browser storage restrictions can reset them.

Stations and favorites are shared configuration. Change them by editing the repository JSON and publishing a new revision. Lite has no station editor, account, sign-in, AI conversation, API-key storage, weather widget or Google Search widget.

Live audio and markets require internet access. Lite does not bundle offline audio or an offline application cache. Browser and vehicle restrictions can affect playback.
